quibble

Comment on any HTML. Send the feedback to your AI.

A drop-in text & element commenting layer for AI-assisted iteration. One script tag, no dependencies, no backend.

Try it on this page ↓ View on GitHub

Install

<script src="https://cdn.jsdelivr.net/gh/OnrampLab/quibble@latest/quibble.js"
        data-project="my-mockups"></script>

That's it. A floating Element / Feedback bar appears in the bottom-right. This very page loads quibble the same way.

The loop

1

AI drafts HTML

Your agent generates a document, mockup, or questionnaire as a web page.

2

You quibble

Select text or click an element, leave a comment. It highlights and persists.

3

Copy JSON → AI

Paste the structured feedback back to your agent. It regenerates. Repeat.
