What's new in this RC

  • Settings panel — a ⚙ gear in the Feedback panel header opens a config panel. Preferences persist in localStorage.
  • Element picking switch — a ⌖ toggle in the Feedback panel header arms element picking (no more bar button). It's sticky: stays armed after each pick until you press Esc.
  • Default mode on load — set Element so that switch is armed automatically on every load (#2).
  • Export format — choose JSON, YAML, or Markdown; both Copy and Export follow it (#1).
  • Theme — set accent / bar colors and font right from the panel.
  • Project / storage key — rename the project or switch the storage namespace without editing the script tag.

<script src="https://cdn.jsdelivr.net/gh/OnrampLab/quibble@v1.1.0-rc.1/quibble.js"
